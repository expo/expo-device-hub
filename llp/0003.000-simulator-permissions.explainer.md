## Scope

This document explains the native Simulator permission helper. Paths beginning
with `src/` or `Sources/` are relative to `packages/serve-sim/packages/serve-sim`.
Other paths are relative to the repository root. [observed:
`Sources/SimPermissions/sim-permissions.m`]

## Native services

Notification state belongs to BulletinBoard, privacy permissions to tccd, and
location to locationd. The helper exposes separate commands for these services;
BulletinBoard does not control other permission families. [observed:
`Sources/SimPermissions/sim-permissions.m`]

### Notifications

The helper loads BulletinBoard and uses `BBSettingsGateway` to read and write
section information. Grant sets authorization 2, denial sets 1, and reset sets 0
while retaining an existing section. Reset of an absent section is a no-op.
Grant can create a section before installation. [observed:
`Sources/SimPermissions/sim-permissions.m`, `notifications`]

Required selectors are checked before publishing. `allowsNotifications` also
affects authorization, so the explicit authorization status is written last.
Readback confirms status, allowed state and the critical flag. Grants also set
and confirm enabled lock-screen and Notification Center settings (2). Missing
APIs, exceptions and unconfirmed writes fail. Private API availability is not a
promise for untested runtimes. [observed: `Sources/SimPermissions/sim-permissions.m`]

### TCC privacy permissions

TCC changes use `TCCAccessSetForBundleIdWithOptions` or
`TCCAccessResetForBundleIdWithOptions`. The helper requires `kTCCSetNoKill`, passes
the no-kill option and checks the daemon's Boolean result. A successful change
does not guarantee that every app framework invalidates cached authorization.
[observed: `Sources/SimPermissions/sim-permissions.m`, `tcc`]

### Location

Location reads use locationd's saved app entry in `clients.plist`. The helper
does not modify that file. Location changes remain the responsibility of
`simctl privacy`. [observed: `Sources/SimPermissions/sim-permissions.m`,
`location`; `src/permissions.ts`]

## Helper, fixture and packaging

The helper build embeds scoped TCC and BulletinBoard entitlements in the Mach-O
`__TEXT,__entitlements` section, then signs ad hoc without private code-signing
entitlements. The private entitlement in the signing blob was rejected by
Simulator spawn policy in the initial experiment. The helper does not inject
code or restart the target app or SpringBoard. [observed:
`Sources/SimPermissions/build.sh`, `entitlements.plist`; native notification
experiment, 2026-10-23]

The arm64 binary ships as `dist/simperm/serve-sim-permissions`. Build sources are
excluded from the package. Hub receives the helper through its packed vendor
copy. [observed: serve-sim `package.json`, `build.ts`;
`packages/expo-device-hub/package.json`, `packages/expo-device-hub/scripts/vendor.ts`]
