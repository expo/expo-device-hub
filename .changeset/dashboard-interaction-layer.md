Dashboard controls now share one hover, press, and keyboard focus behavior. Buttons, selects, switches, text fields, and device rows show the same blue focus outline for keyboard focus; the titles of the sidebar sections keep the browser's outline. A hover fill no longer stays on a control after a touch, and a locked control no longer reacts to the pointer. The toolbar tooltips and the hints of disabled controls use the same tooltip.
