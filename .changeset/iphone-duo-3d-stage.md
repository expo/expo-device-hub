The iPhone Duo's 3D model is now as large as the 2D preview, which uses the same 480 px short-side cap as other devices, in place of serve-sim's fixed 580 px square. In a small window it shrinks to the stream area between the device name and the toolbar. Folding, rotating, or switching displays never resizes it, and the 2D preview keeps its size.
