In a large window, the iPhone Duo's 3D model is about as large as the 2D preview, which uses the same 480 px short-side cap as other devices. In a smaller window the 3D stage shrinks to the stream area between the device name and the toolbar, and the model keeps a 32 px margin on each side, so there it is 64 px smaller than the 2D preview. Folding, rotating, or switching displays never resizes it, and the 2D preview keeps its size.
