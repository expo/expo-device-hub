# GPU frame capture experiment moved

The maintained experiment now lives in
[`@expo/emulator-capture`](../../packages/@expo/emulator-capture/README.md).
It remains private and experimental. Use its package.json scripts to build,
run capture, and execute tests. No package has been published.

Disposable workflow helpers and raw historical measurements are kept outside
the repository. The package README retains a summary of the measured results.
