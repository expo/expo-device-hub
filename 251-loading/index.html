Definition: loadeddata measures time from assigning the fresh media source until a frame for the current playback position is available. The first video-frame callback measures callback delivery when a frame is submitted for composition. It is not a pure decoder-latency measurement. Range requests are counted from the loopback server.


Limits: This tests loading from an artificial range server in the current local browser. It does not measure hosted performance, capture smoothness, or sustained playback drops. Unique URLs and no-store responses prevent reuse of these media resources; decoder and process initialization can remain warm. All trials and invalid reasons are retained.
